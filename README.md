## 📌 Overview

**SEEDSOLVER** is a Windows Forms project that serves as a **seed generator** and also allows the **recovery of an existing seed**.
The application displays a professional monitoring interface with system information, animated status indicators, and a generated 12‑word phrase.

## ✨ Features

### 🖥️ Modern Dark Interface

- Professional dark theme
- Dashboard‑style layout
- System‑monitoring panel
- Clean UI design
- Real‑time animated values

### 📊 System Monitor

Shows real‑time data for:

- CPU usage
- Memory usage
- Processor information
- Thread count
- Operating system
- Network status
- Security status
- Uptime

### 🔑 Seed Generator & Recovery

- Generate random 12‑word seed phrases
- Visual processing animation

### ⚡️ Interactive Process

- Start button
- Progress animation
- Status changes
- Dynamic dashboard updates
